Spec: [PLAN.md](PLAN.md). Every agent edits **only its own table** (plus "Bugs found" for Agent D and
"Contract change requests" for anyone). All `src/` paths below are relative to `src/support_agent/`.

**Status values:** `⬜ todo` · `🔄 in progress` · `⏸ done, awaiting approval` · `✅ done` (approved) · `⛔ blocked`

**Update rule (mandatory):** set a row to `🔄 in progress` the moment you pick it up, and to `⏸ done, awaiting approval`
the moment it's finished. Fill in the date and the note right away; don't batch updates. If the files or key
components you actually built differ from the plan in the row, **update the Files / Key components cells** to match.
Keep your row in the Progress summary current.

**Approval gate:** ~~stop after each task until the user says "proceed"~~. **Lifted by the user on 2026-10-16**
("don't stop for my approval, complete all tasks"). Agents now run their remaining tasks back to back and mark each
one `✅ done` themselves as soon as it's finished. `⏸` is no longer used.
